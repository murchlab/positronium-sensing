# si_figures

Supplementary-information figure exports produced by the notebooks.

Typical outputs include:
- `integration_weights*.{png,pdf}` from `notebooks/07_readout_integration_weights_demo.ipynb`
- Singlet FI panels exported by the singlet analysis notebooks:
  - `SI_fig_v3_a.pdf` (readout-corrected)
  - `SI_fig_v3_b_raw.pdf` (raw reconstruction)
  - `SI_fig_v3_c_gate.pdf` (gate-corrected)
- Combined panels exported by `notebooks/06_combined_si_figures_and_fig3.ipynb`:
  - `SI_fig7_combined.pdf`
  - `SI_fig8_average_FI.pdf`

Main-text figures are written to `main_text_figures/` instead.
