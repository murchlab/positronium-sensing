# figures

Small image assets used in the documentation and explanatory notebooks.

Contents:
- [`readout_fidelity_Q1Q2.png`](./readout_fidelity_Q1Q2.png): measured two-qubit readout confusion matrix (used in [`notebooks/08_readout_fidelity_correction_ibu_demo.ipynb`](../notebooks/08_readout_fidelity_correction_ibu_demo.ipynb)).
- [`readout_fidelity_correction.png`](./readout_fidelity_correction.png): example output comparing uncorrected vs corrected probabilities (generated by [`notebooks/08_readout_fidelity_correction_ibu_demo.ipynb`](../notebooks/08_readout_fidelity_correction_ibu_demo.ipynb) and embedded in the docs).

This folder is not the main output location for publication figures; see [`si_figures/`](../si_figures/) and [`main_text_figures/`](../main_text_figures/) for notebook-generated exports.
