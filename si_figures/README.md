# si_figures

Supplementary-information figure exports produced by the notebooks.

Typical outputs include:
- `integration_weights*.{png,pdf}` from `notebooks/02_readout_integration_weights.ipynb`
- `SI_fig_v3_{a,b_raw,c_gate}.pdf` from the singlet FI analysis notebooks
- `SI_fig7_combined.pdf`, `SI_fig8_average_FI.pdf` from `notebooks/04_combined_plots.ipynb`

Main-text figures are written to `main_text_figures/` instead.
