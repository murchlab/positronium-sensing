# data_analysis

This folder contains derived products generated by the notebooks:

- `*_alpha_P_FI_*.csv` files with three columns: `alpha_rad, P, FI`.
- `Q1_*` / `Q2_*` files: single-qubit FI curves.
- `singlet_*` files: singlet-state FI curves (raw, readout-corrected, and gate-corrected).

These files are consumed by the figure notebooks (`notebooks/06_*` and `notebooks/07_*`).
